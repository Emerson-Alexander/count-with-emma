# Count With Emma

A private, static register closeout helper. It runs entirely in the browser: no data is stored, transmitted, or sent to a server.

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server.

## Publish on GitHub Pages

In the repository settings, open **Pages**, select **Deploy from a branch**, then choose the `main` branch and `/ (root)` folder.

The site has no build step or dependencies.
